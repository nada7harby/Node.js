# دفتر مذاكرة Node.js

مرجع عربي تفاعلي لمذاكرة **JavaScript وNode.js وExpress** والاستعداد للمقابلات التقنية. المشروع عبارة عن صفحة HTML واحدة تعمل مباشرة في المتصفح، وتجمع الشرح المبسط، الأمثلة العملية، الأخطاء الشائعة، أسئلة المقابلات، وملخصات المراجعة السريعة.

## المميزات

- 22 فصلًا و219 موضوعًا، بدايةً من مراجعة JavaScript وحتى بناء REST APIs وتأمينها.
- أكثر من 550 مثالًا وكتلة كود مع شرح عملي.
- بحث فوري داخل قائمة الموضوعات.
- قائمة جانبية تُبنى تلقائيًا من محتوى الصفحة، مع تمييز الموضوع الحالي أثناء التمرير.
- تصميم عربي من اليمين إلى اليسار ومتجاوب مع الهاتف والشاشات الكبيرة.
- تلوين بسيط لأكواد JavaScript من دون مكتبات إضافية.
- ملخصات، أسئلة مراجعة، أخطاء شائعة، ونماذج لأسئلة المقابلات.

## المحتوى

يغطي الدفتر الموضوعات التالية:

- JavaScript الحديثة: الدوال، الكائنات، المصفوفات، الـ destructuring، الـ promises، و`async/await`.
- طريقة عمل Node.js: محرك V8، الـ Event Loop، الـ Thread Pool، والـ processes.
- Streams، ومسارات الملفات باستخدام `path`، والتعامل مع الملفات باستخدام `fs`.
- HTTP وExpress والـ routing والـ middleware والتعامل مع request body.
- تصميم REST APIs وتنفيذ عمليات CRUD.
- Sequelize وقواعد بيانات SQL.
- معالجة الأخطاء والكود غير المتزامن.
- خصائص الـ API مثل filtering وsorting وpagination.
- Logging وDebugging.
- Authentication وAuthorization وJWT وCookies وSessions.
- Validation وSanitization ورفع الملفات باستخدام Multer.
- Cheat sheets ومراجعة نهائية سريعة.

## التشغيل

لا يحتاج المشروع إلى تثبيت حزم أو تنفيذ build. افتح ملف [`index.html`](./index.html) مباشرة في متصفح حديث.

ويمكن تشغيله من خلال خادم محلي اختياريًا:

```bash
npx serve .
```

ثم افتح العنوان الذي يظهر في الطرفية، وغالبًا يكون `http://localhost:3000`.

> يحتاج الخط المستخدم في التصميم إلى اتصال بالإنترنت عند أول تحميل لأنه يُحمَّل من Google Fonts، أما المحتوى ووظائف الصفحة الأساسية فتعمل محليًا.

## تعديل المحتوى

كل فصل داخل `index.html` هو عنصر يحمل الصنف `chapter`، وكل موضوع داخله يحمل الصنف `topic`. تعتمد القائمة الجانبية على الخاصية `data-navlabel` ومعرّف `id` لبناء روابط التنقل تلقائيًا؛ لذلك احرص على أن يكون لكل موضوع معرّف فريد عند إضافة محتوى جديد.
